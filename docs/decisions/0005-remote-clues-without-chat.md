# 5. Remote play: typed clues and suspicion taps, no chat

- **Status:** Accepted
- **Context:** In online rooms players may not share a call or a room, so they need a way to give clues and discuss. A full in-app chat brings moderation, abuse limits and message history, which is a lot for a party game.
- **Decision:** The host picks a clue mode per room. **Typed**: one-word clues go to a shared clue board. **Spoken**: players talk on their own call; the app tracks turns. For discussion, players **tap clues they find suspicious**, and the counts are shown to everyone. There's no free-text chat.
- **Consequences:** Nothing to moderate beyond names and one-word clues. Less nuance than open discussion; groups that want banter use a call with Spoken mode. Chat can be revisited if players ask for it.
